Readest Lite

快速开始

docker run -d \ --name readest-lite \ -p 8225:8225 \ -v readest-data:/data \ -e ADMIN_EMAIL=admin@example.com \ -e ADMIN_PASSWORD=your-password \ ghcr.io/cshdotcom/readest-lite:latest

然后访问 http://localhost:8225

核心功能

📖 电子书阅读

支持 EPUB / PDF / MOBI / AZW3 / CBZ / FB2 / TXT / Markdown 格式，基于 foliate-js 渲染引擎

🔐 多用户 + 角色层级

super_admin > admin > user 三级角色，JWT 认证，每用户 AES-GCM 加密 vault

💾 存储配额

管理员可设置每用户的存储/翻译配额，文件去重 + 引用计数

🗑️ 回收站

删除书籍移入回收站，30 天自动清理（可配置），批量恢复/删除

📁 分组管理

书库三点菜单 → 分组管理：搜索/添加/编辑/删除/排序，与书库 GroupBy 融合

🔄 跨用户文件管理

管理员可浏览所有用户文件，批量移动/复制到其他用户

📤 书籍分享

生成分享链接（1 天/3 天/7 天/永久/自定义日历），接收方独立副本

📥 远程下载

从 URL 下载书籍，支持批量下载、Cookie/Headers、自动重命名

📊 阅读统计

月度/周度/今日阅读统计，书籍阅读进度排行

📝 笔记同步

Notion 笔记同步（代理路由）、ReadEra 注释导入、带登录的网页小说导入

🌐 RSS 订阅

订阅 RSS 源，文章自动转为书籍，支持 OPDS 目录

🎨 头像 + 主题

用户头像上传/删除，深色/浅色/自动主题
